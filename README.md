# Calculadora Web

Aplicação de calculadora desenvolvida com HTML, CSS e JavaScript puro, com suporte a operações matemáticas básicas, histórico de cálculos e interação via teclado.

O projeto foi criado com foco em prática de manipulação de DOM, eventos JavaScript e construção de interfaces modernas e responsivas.

## Funcionalidades

- Operações matemáticas básicas
- Suporte a teclado
- Histórico de cálculos
- Limpeza individual e total da expressão
- Scroll customizado no histórico
- Atualização dinâmica da interface
- Layout responsivo

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Conceitos Aplicados

- Manipulação de DOM
- Eventos de clique e teclado
- Atualização dinâmica de elementos
- Estruturação de layout com Flexbox
- Organização de funções JavaScript
- Controle de estado da aplicação

## Funcionalidades do Sistema

### Calculadora
- Soma
- Subtração
- Multiplicação
- Divisão
- Porcentagem
- Números decimais

### Histórico
- Registro automático das operações
- Exibição dos resultados
- Limpeza completa do histórico

## Objetivo do Projeto

O objetivo do projeto foi praticar lógica de programação, manipulação de eventos e desenvolvimento de interfaces interativas utilizando JavaScript puro.
